# 2026-10-06: serve acts only as the account it started as (batch 109)

From the v0.3.0-rc6 full stage's D-C2, and the person's "Fix for final rc" (17:47Z). A running serve held its GitHub client, and the token in it, past `setup github --logout`, acting as the person until the token expired; then it read the credential chain again, and with the Keychain empty could have gone on with the GitHub CLI's token, another account's, and pushed or opened a pull request as that account.

## What changed

- **serve reads who its login acts as, afresh, each minute** (`github.IdentityWatcher`: the credential chain read again, GitHub asked who a token is only when the token changed), and pins the account it first finds.
  - **No login:** it says once "serve: no GitHub login now; it reads pull requests without one, and opens, pushes, and checks on GitHub nothing until dockhand setup github logs in", reads pull requests without one, and starts no check on GitHub and no submission.
  - **Another account's:** it says once "the GitHub login is now bob's, where serve started as ada's; it acts on GitHub as no one until ada logs in again, or serve is restarted", and does nothing on GitHub, reads included.
  - **Its own back:** it says "serve: logged in again as ada; acting on GitHub again", with no restart.
  - Each change lets go of the client the engine held, and its token (`Engine.dropForge`), so the next use reads the login as it is.
- **status and queue say why serve isn't acting on GitHub,** "serve: running (pid N) · not acting on GitHub: no GitHub login", from serving.json; `--json` has it as `serve_state.not_acting`.
- The README's known issue goes, and its serve paragraph says how serve acts on a logout.
- **D-C2** sets the GitHub CLI's login aside with the Keychain's, since dhtest's CLI is the test account's, and passes when serve says once it has no login, says the closed test pull request, says the login is back, and runs as one process throughout.

## Verification

- Tests: a serve whose login reads as ada, none, none, bob, and ada says no login once, the other account, and ada's return; status's words; the watcher asks GitHub only when the token changes, and says when there's none.
- The full checks: fmt-check, vendor-check, vet, lint, deadcode, and the suite under MacPorts (port-tclsh).
