## Decided along the way

- **An uncertain correspondence holds.** A port with several archives renamed past telling apart was compared by their order, which could judge one archive by another's files. Holding asks a person the question the order guessed at; it should be rare, since names that differ only in their versions match.
- **A license kept by its text still holds where text beside it changed.** "is still MIT by its text, and changed beside it" holds as "changed" did, since the holding policy is the person's (a dropped clause holds, as decided for entr). Whether a classification unchanged at full coverage, and named by the Portfile's line, could hold nothing is a question for them.
- **go-spdx validates; the structure stays dockhand's.** It exports no parse tree, only validation, normalization, and extraction, so `macports.License` reads the normalized expression's terms itself, by SPDX's precedence.
- **The vectors' two differences are deliberate:** local labels set aside in ordering, and ordering of strings that aren't versions unknown, where packaging's newer rules say false; the README says so.
- **Alike is by content, not by words.** Two archives' "LICENSE changed" read alike whatever each said; a change is one where the file's content at each end is the same in each archive, so the review's probe, MIT to GPL beside BSD to Apache, is two, and a license both archives carry, changed alike, stays one, as update's test of it had.
- **A member's `workspace = true` dependency compares as "workspace".** Its version is the root's, compared there; resolving it in each member would count one move once per member.
