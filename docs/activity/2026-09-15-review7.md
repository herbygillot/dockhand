## Accepted changes

- Committed the package-documentation pass, including a five-group navigation map
  in `workflow/doc.go`. The new `outdated` package also has its own overview.
- Removed the native MacPorts discovery dependency from the `verify` contract.
  The original coverage types were not independent values: they embedded native
  evaluator and index structures. Discovery now projects a consumer-owned neutral
  contract with source-bound tool requirements and coverage diagnostics. See the
  [coverage report](2026-09-15-coverage-boundary.md).
- Extracted read-only source scans from application composition into `outdated`.
  The application constructs integrations/cache configuration; the capability
  owns capture, selection, workspace lifetime, and per-port observation. See the
  [outdated report](2026-09-15-outdated-boundary.md).
- Updated dependency rules for verification contracts, native discovery,
  verification staging, PortIndex, and application composition. Added focused
  import regressions for `verify` and `outdated` rather than a general lint system.
- Corrected component-map statements that still described dependent integration
  as future work or placed shared VM launchd control inside the verifier.

## Deliberate limits

- Keep workflow together. Its shared claims, phase checkpoints, and recovery
  mechanisms remain cohesive. Future PR observation and review controls should
  reuse those mechanisms; whether they fit existing phases must follow their
  actual durable semantics, not a fixed phase-count target.
- Defer the PortIndex reader/cache split until query work needs it. The proposed
  seam is real, but current consumers stage and read; this pass adds no selector
  behavior requiring that change.
- Keep object-ID validation in Git rather than adding behavior to record types
  solely to remove a small mechanical dependency. `verify` now imports only Git
  validation and records from the project.
- Keep provider-selection policy and maintenance composition in app for now.
  They do not justify another framework or package in this pass.
- Keep preparation's native integration tests: inspected cases establish dirty
  checkout isolation, stored candidate fidelity, and tag-mutation detection across
  Git, editing, and upstream boundaries. Test/production line ratio alone is not
  grounds to relocate them. Broader CLI fixture deduplication remains targeted
  follow-up rather than a bulk test move.
