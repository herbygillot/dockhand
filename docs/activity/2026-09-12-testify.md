# Testify conversion — 2026-09-12

## Changes

Added `github.com/stretchr/testify` v1.12.1, matching the version currently used by Dockhand v1. `go.yaml.in/yaml/v3` v3.0.5 is its indirect dependency for the assertion packages. The module checksums match the existing v1 dependency checksums, and `go mod tidy` resolves the v2 test imports.

Converted all nine test files in `internal/workflow`, `internal/ledger`, and `internal/tcl/syntax` to `testify/require`. Removed the custom `must` and `require` helpers and replaced handwritten fatal assertions with explicit equality, error, length, nil, ordering, and panic checks. Compound assertions are split so failures identify the specific unmet expectation and required length/nil checks still stop the test before later accesses. Typed values retain their concrete types in equality expectations.

The 34 behavioral tests, two fuzz targets, fixtures, fake clock, provider scripts, and synchronization barriers remain. Goroutines continue returning results to the test goroutine; fatal assertions are not introduced inside worker callbacks. No production implementation changes were needed for this conversion. The commit also includes the previously completed behavioral suite, Tcl list fixes, and their documentation.

## Validation

- `go test -race ./...` passed from `~/Source/dockhand2`.
- Both syntax fuzz targets passed with two workers for 10 seconds each: 140,118 parser inputs and 178,655 list inputs. Existing seed and cached corpus cases also passed.
- `go vet ./...` and `go mod verify` passed; all modules verified against their checksums.
- Formatting and whitespace checks passed. Confirmed that every original test/fuzz entry point remains, every test file uses Testify, and production Go files are unchanged from the preceding behavioral-test work.

## Provenance

The conversion was authored against the new v2 tests. Only the dependency version and checksums were taken from the v1 module files; no v1 tests or comments were copied. The earlier [behavioral test report](2026-09-11-behavior-tests.md) documents the original suite and the list-decoding defects it found before adopting Testify.
