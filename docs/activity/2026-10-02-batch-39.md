# 2026-10-02: package names (batch 39)

Batch 39 of the [roadmap](../roadmap.md): Codex's [package names and layout review](../reviews/2026-10-02-package-names-and-layout.md) of 034417d0, taken where its claims held against the code and at the person's word, before item 7's rest so the batches after it land on the new names.

## What changed

Seven renames, each its own commit with no change in behavior: package clause, import paths and qualifiers (gopls), directory, boundary-test allowlists, package comments, and the live docs.

- **`version` → `buildinfo`.** It reads this binary's own version, revision, and modified state; `command` already imported it beside `macports/version`, a port's version spelling. The `-ldflags -X` path is now `internal/buildinfo.Version`, in the Makefile and `docs/development.md`; a build stamped that way said `dockhand v0.9.0`. A Portfile or script that stamps dockhand's version changes with it.
- **`text` → `textedit`**: byte spans, positions, and checked edits.
- **`macports/dependency` → `macports/depblock`**: Go and Rust dependency blocks, not a port's dependencies.
- **`portedit/archives` → `macports/distfetch`**, the one move of ownership: the editor, `editprep`, and the engine's assessment and archive diff all download through it.
- **`tart/channel` → `tart/guestssh`**: Apple's ssh to a Tart guest.
- **`macports/newport` → `macports/portcreate`**, decided earlier the same day; the new-port policy moves into it with `create`'s batch.
- **`preparation` → `editprep`**, the person's name in place of the review's `macports/portprep`: it prepares one Portfile edit against an immutable tree, and under `macports` it would have blurred a folder of MacPorts facts and rules with Git and release work.

With them, the stale owners the review found: `tart`'s comment named `verify/tart`, `forge`'s `publish`, and the architecture `engine.Counts`, now `evidence.Counts`. The review's claim that `engine/body.go` was stale didn't hold: it still holds the description's facts.

## Not taken

- **The secondary names** (`history`, `planning`, `selection`, `survey`, `github`, `tart/host`): when those areas next change, as the review itself suggests.
