# Version inputs in switch arms and eight more setup procs

The whole-tree survey's largest genuine bucket, 1,317 ports with no editable version input, reported zero candidates for almost all of them rather than inconclusive ones. That pointed at discovery, not probing: the candidate scanner recognized `version`, `set`, the GitHub, GitLab, and Go setups, and the Perl, R, and Ruby ones, and it descended into `proc`, `platform`, `variant`, `subport`, `foreach`, and `if` bodies. Two shapes were outside it.

The first is `switch`. php chooses its version per branch inside `switch ${subport_branch}`, one Portfile carrying 605 ports. The scanner now walks a switch's arms in both spellings, the single braced list of alternating patterns and bodies and the inline pairs after the string, past any leading options. Patterns are not inputs; a `-` body falls through and is not braced, so it is passed over. The inline form was missed on the first attempt by an off-by-one, since after the option loop the index already sits on the switched string; the test covers both forms and checks a replacement lands on the literal's own span.

The second is a set of PortGroups whose setup proc takes the version positionally. Dictionaries, fonts, cross toolchains, and Pure modules take it second: `aspelldict.setup locale version lang`, `hunspelldict.setup locale version lang`, `x11font.setup name version subdir`, `pure.setup module version`, `crossbinutils.setup target version`. Bitbucket and Codeberg take it third, after author and project. `octave.setup` keeps a two-argument `module version` form beside its full `repo author module version` one, and three arguments name no version at all, so its rule depends on arity. Each position was read from the PortGroup's own proc signature rather than inferred from Portfiles.

One port from each family was assessed against the tree. Dictionaries, fonts, Pure, Octave, and Codeberg ports are ready outright. php84 finds its input at line 198 in 39 seconds for the whole probe and is now unknown rather than unsupported, stopped by a filesystem read outside the tree at line 254, which is the host-state bucket and a separate lever. `aarch64-elf-binutils` finds its input and stops on a calculated checksum algorithm; `Coin` finds its input and stops on Bitbucket fetch customization. By the survey's counts, about a thousand ports gain a version input, and roughly 340 of them become ready on this change alone; the rest wait on the checks named above, which is what the assessment now says about each of them.
