# Three fixes found after rc3 (v0.4.0)

Found while Codex's review was checked against main (a268b6e5), and placed
under Next's first paragraph by the coalesced roadmap (8ac426e2). Whether
they go into v0.4.0 as an rc4 is the person's call; no candidate is cut
for them until then.

- **`ship --mine` leaves no empty branch.** c360b35f moved the batch onto
  `author`, which never set `UpdateRequest.NoHandBranch`, so each port
  dockhand can't edit kept an empty branch. `shipOne` sets it for a batch
  and for a ship nobody looks over (`--yes` or no terminal), as serve's
  path does; the refusal says "No branch was started." where it said
  "Kept: <branch>, with nothing changed." A person's own `ship <port>` on
  a terminal keeps one for the edit by hand.
  TestShipStartsNoBranchForAnEditItCantMakeUnattended.
- **A hand edit `ship` holds names the way on.** Under `ship --yes`, the
  hold quoted tidy's refusal, "apply it as shown with --yes", which ship's
  `--yes` doesn't do. `TidyPlan.HeldForLook` is the hold serve's ship
  already said, "the edit needs a look before it is committed: dockhand
  tidy --branch <name>", now the engine's for both: `goOn` returns it, and
  `tidyBranch` returns it before `decideTidy` where there's no terminal.
  TestShipWithYesHoldsWhatServeWould's last step expects it.
- **`dockhand setup` counts a golden copy.** `tart.Status` gains
  `Restorable`, the releases with no base image and a golden copy, and
  `HostRestorable`. The providers line says "macOS 26's image was deleted
  and its golden copy kept: dockhand setup tart tahoe restores it, in
  about a minute" where it said "not set up" and up to 60 GB, and setup's
  offer asks to restore, with no download. `setup tart` already restored
  it. TestStatusListsReleasesWithImages, TestProviderLinesShowTheImages,
  TestSetupShowsTheProviders.

## Two harness fixes from the rc3 rerun

The rc3 rerun batch (12:38Z) had no product failures; two rows' harness
was wrong.

- **B9:** its grep was anchored at the line's start, `^ *tart +· not set
  up`, and setup's line begins "Providers    tart · not set up", so a
  check that passed on GitHub (run 39030172979) failed the row. It now
  takes `tart` at the line's start or after two spaces.
- **A10:** a `cd "$(dockhand path go-reflex-…)"` example took the first
  matching Git branch, which was D-I7's leftover go-reflex branch, so the
  examples ran there. `a10_branch` takes the newest matching branch that
  wasn't open before the row (branches.before), and the newest of any
  where none is the row's.
