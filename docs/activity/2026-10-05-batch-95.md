A merged branch of the name isn't quietly replaced either: it takes no changes, and `start <name>` starts a new one of the name on purpose. A `--plan` starts nothing: an update's plans against master, where the branch would start, and revbump's says it would start it without `--plan`. The commands about a whole branch, `check`, `tidy`, `submit`, `diff`, and `status`, still refuse a name no branch has. `--help` and usage.md say so.
