# update --hand-edit

2026-10-25, Then's item 3 (the reflections' A, the 2026-10-09 wishlist's
second). Where update refuses, an attended update with `--hand-edit`
writes dockhand's best attempt for the person to finish, recorded as the
person's hand edit with the refusal's reason. The record's shape is
architecture's, settled on the thread (option B).

- **The attempt** (portedit `HandAttempt`): the refused edit where the
  refusal came with one, as strict fidelity's does, else the version
  written as its one literal (`portfile.SetVersionLiteral`) with the
  revision reset; then the checksums refreshed for the new version's
  archives. What couldn't be written is in `Left`, with why.
- **editprep** asks for it where `Request.HandEdit` is set and the
  refusal is of the Unsupported kind, and returns it with `Refused`, its
  tree unproven, since it's the person's.
- **The record**: no edit of dockhand's. A ledger decision,
  `model.FindingHandEdit`, answered `model.ByHand`, its subject the
  port's directory, its evidence the attempt's digest, and its new
  `Words` the refusal ("jq to 1.8.1: …"). `Words` is a decision's words,
  whoever wrote them, which the person's voice (Then's item 13) will use
  for a person's reason. Schema 40 adds the column; store
  `BranchDecisions` reads a branch's decisions on a finding, whatever
  their evidence.
- **Readers** (engine `handEdits`): kept through tidy, which commits the
  directory as the person's; lapsed where the directory is the base's
  again; "as written" or "adjusted by hand" by the digest. tidy's plan
  notes it, and the unattended commit gate says it with the way on
  (branchstate `CommitUnasked`); status says it ("By hand") and carries
  `hand_edits` in its JSON; the pull request's Description lists it
  before the person's note.
- **Attended only**: the engine refuses `HandEdit` with `Unattended`.
  An attended update's refusal names the flag as its last step.
