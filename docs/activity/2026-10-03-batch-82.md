## What changed

- **with_timeout kills what ignores the alarm.** It exec'd the command under a perl alarm, which leaves the signal to the command, and Go ignores SIGALRM: D-R2's `with_timeout 180 dockhand check` ran 2h47m, dockhand rightly waiting on the two-VM limit. A parent now forks the command, sends TERM at the deadline and KILL five seconds on, and exits 142. The self-test runs a command that ignores both ALRM and TERM.
- **What a command spends of GitHub's API is said.** The test account's 5,000 requests an hour went between A0 and B1, and nothing said which command spent them. `github.Requests` counts each request the process sends GitHub's API, each retry too; every `--json` envelope carries `github_requests`, and `-v` says "GitHub's API: N requests". The harness records each row's spend in its result, from GitHub's `rate_limit`, which costs none of the allowance.
- **Two Tart tests read the stage's Tart home** (A0). With `DOCKHAND_TART_HOME` set, as the quick stage sets it, the state directory is the stage's (batch 77), and the tests that check `~/.dockhand` now clear it for themselves.
