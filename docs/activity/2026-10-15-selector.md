# -b names an existing branch, --new=<name> starts one, through engine.Selector (v0.4.0 part 1, c)

The command-line UX second look's §1 and §3 (added for v0.3.1 at the
person's "Go ahead", 2026-10-10, as `ship -b` builds on it), built in the
shape of the command package review's `engine.Selector`, and asking the
split's 7d row 7's two questions as one.

- **`engine.Selector{Branch, PR, Port, New, NewName, Policy}` and
  `Engine.Select`** decide which branch a command works in, returning a
  `Selection`: the branch found (with `Said`, how it was chosen for the
  port), the branch to start, or the choices. `SelectExisting` is a
  command about a whole branch (`-b`, `--pr`, `-p`, else where it runs);
  `SelectOrStart` an authoring command (`-b`, `--new`, where it runs, an
  untracked branch here that changes the port refused for `adopt`, else
  the port's branch, one started for it where none changes it). It
  replaces `chooseBranch`'s body, `branchFlags.resolve` and `portBranch`,
  create's `-b`, revbump's `-b`, and `namedOrStarted`, which goes.
- **`-b` names an existing branch, everywhere.** `edit jq -b jq-typo`
  said "Started dockhand/jq-typo" with no question; it's refused, "no
  tracked branch named jq-typo; --new=jq-typo starts one" (the hint where
  a branch may be started). A Git branch of the name dockhand doesn't
  track points at `adopt`; a merged branch's is said from its record,
  "--new=<name> starts a new branch of the name". A plan with an unknown
  `-b` is refused as well, where it was planned on master.
- **`--new=<name>` names a new branch**, on update, checksums, edit,
  create, and revbump (which had no `--new`); `--new` alone still chooses
  the name, for the port or the version an update moves to.
- **One question** where several open branches change the port: "jq is
  changed in 2 open branches: 1. jq-one 2. jq-two ? which one, or n for a
  new branch? [1-2/n]", where it asked "start another? (-b picks one)"
  for an authoring command and "which one?" for `-p`. `-p` offers no new
  branch; a script is told them all, as before (`AmbiguousError`).
- `engine.MergedError` types a merged branch's refusal, which `Select`
  reads, where it matched words.
- usage.md and design-v3.md's revbump example, and acceptance rows D-T1 and A12, start their branch with `--new=<name>`.
