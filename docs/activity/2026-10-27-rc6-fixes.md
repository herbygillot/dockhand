# rc6's three fixes from v0.7.0's lead: I24, I26, and B9

2026-10-27, at the person's "Add Syft + B9 + I24 + I26 + the Tart VM limit
to rc6" (Tart's VMs moved back to v0.7.0 at his word), roadmap 50bed52c.

- **I24, a check on GitHub refuses at once where the fork's workflow
  won't run.** The provider reads the fork's `main.yml` before it pushes
  (ghactions.API's WorkflowState, `GET
  /repos/{fork}/actions/workflows/main.yml`, one request). Missing, or in
  any state but active, it refuses at once, an environment refusal
  naming the state and the fork's Actions page (`WorkflowWords`), where
  it waited ten minutes for a run, and a retry ten more. One that can't
  be read is waited out as before. setup's github line reads the same,
  through the provider's `ForkWorkflow`, where the fork can be found.
- **I26, an incomplete assessment is made again by a newer dockhand.**
  An assessment records the build that made it (model.Assessment.Build,
  schema 42), and `lookAgain` makes again an incomplete one another
  build made, rather than relying on raising `assess.Policy`; a record
  from before has none, so v0.6.0's first look makes again each
  incomplete one an earlier build made. A complete one stands across
  builds.
- **B9, a job GitHub cancelled before a runner took it says so.** A job
  with no runner (`RunnerJob.RunnerName` empty) has no log, so none is
  asked for, where it read "job log: fetch: HTTP 404": the other jobs'
  results are read, and where nothing built, the reason is "GitHub
  cancelled macos-15's job before any runner took it; see <run>", still
  infrastructure, which a retry meets again once GitHub's runners work.
