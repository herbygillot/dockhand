# 2026-09-23: the sweep after the contracts

With the 2026-09-23 review's four contracts landed, a sweep for what
they left behind and for what only tests reach. Three instruments: the
reachability tool with tests as roots, which was clean; the same tool
without tests as roots, which names what only tests reach; and a scan of
the touched packages' exported identifiers and struct fields for those
no production code outside their package uses, with composite-literal
keys and JSON names counted as uses.

## Gone

- A doc comment in `archives/store.go` that still described the deleted
  `ChecksumValues`.
- `ledger.Entry.ID`, called only by the ledger's own test.
- `portindex.SourceFunc`, used only by the selection tests, which now
  carry a three-line private adapter, the way `cli.NewRoot` moved.
- `actionRule.prepares` in the request rules, a fifth spelling of the
  preparing set the single-rules step missed: `Action.Prepares` replaces
  it at its six reads and the table loses five entries.
- `preparation.GeneratedBy`, a one-line re-export of
  `commitmsg.GeneratedBy` that one test called.
- `verify.Capabilities.Isolated`, written by both providers and read by
  nothing.
- `Resolution.Prior`, set on a continued resolution and read by one
  test. `Degraded` stays: the resolution design names it as the one way
  a failure becomes a value, and that is a contract, not a leftover.
- `verify.PlanSingle` with its two helpers, forty lines only the CLI's
  reuse test called; it calls `PlanWithConfig` and takes the first build.
- `app.Status`, a one-line wrapper over `FilteredStatus`; the eleven
  test calls pass an empty filter.
- `Engine.BranchScope` and `Engine.ControlBranch`, thin wrappers over
  `ContributionScope` and `ControlContribution` that one test called;
  it passes a branch selector to the general forms.
- `macports.KnownOption`, reached from nothing in production; its one
  use is the options test's invariant, so it lives there now, unexported.
- `upstream.PatternFromCurrent`, reached from nothing in production,
  with the part of its test that exercised it.

## Looked at and kept

- `state.Reader.Revisions` and `SubmissionsForAttempt` have no production
  caller, but the workflow fixture's state snapshot lists revisions
  through the first and finds an attempt's closed submissions through the
  second, and SQLite's contract test covers both. Removing them would
  weaken the tests to save two ten-line queries.
- `Engine.Provider`, the single-provider fallback, is set only by tests,
  but the workflow tests' build configurations name five providers served
  by one scripted provider. Removing the fallback means registering that
  provider under every name, a fixture contortion in exchange for one
  field.
- The seven functional options on `tcl/rpc` and `tcl/shell` are exercised
  only by those packages' contract tests; they are the libraries' knobs.
- `macports.NewTree`, `workspace.Adopt`, `github.TokenSourceFunc`, and
  `Engine.PreparationInput` are used by tests in other packages and
  cannot move into a test file; each now says so in its doc comment.
- The seven engine fields only tests set, `Owner`, `Timeouts`,
  `LeaseGrace`, `RetryDelay`, `PullRequestInterval`, `WaitInterval`, and
  `ObserveInterval`, are not dead: production runs on their defaults.
  Whether they become one tuning value is a design question left open.
