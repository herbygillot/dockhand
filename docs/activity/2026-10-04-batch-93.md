# 2026-10-04: review starts at the pull request's own base (batch 93)

Batch 93 of the [roadmap](../roadmap.md): from the M1's quick run at d302e744 (write-up: the project library's `plan/quick-run-2026-10-04-b.md`).

## What changed

- **review starts at the pull request's own base.** E9's `review 34756 --markdown` ran 99 minutes building a PortIndex, its workspace holding lang/php and `_resources`, though #34756 adds sysutils/dockhand alone. The quick stage pins MacPorts' upstream at 026b3878, months old. Review took the merge base of that master and the pull request's head, so everything MacPorts changed since counted as the pull request's change: each port assessed, and an index built of the tree. The forge now reports how many commits a pull request has (`forge.PullRequest.Commits`, GitHub's documented count). Where master here leaves more than that between it and the head, review starts from the head's own base, that many commits back. It says so: "master here is behind #34756's base, N commits past it to its head where the pull request has 1 commit, so it's reviewed from …". A user's master, which review fetches fresh, isn't behind, but a clone whose upstream is a stale mirror is.
- **The index isn't read for a new port.** A directory the source's tree has no Portfile in is a new port's: its index names none of its ports and nothing as depending on them. So the readers of the index that name a directory's ports or its dependents (`Engine.portsDefined`, `Engine.dependents`) leave such directories out, and don't build an index for nothing. A review of a new port's pull request reads no index at all.
- **B3's runs left running are by design, and said.** Stopping `serve --drain` mid-check leaves its runs running for the next serve, which resumes them first (Design v3 §11; `TestAStoppedServeLeavesTheRunForTheNext` covers it). `queue` says each is "stopped: the process running it ended; dockhand wait check-N resumes it, cancel ends it". The harm the run recorded came from the harness cutting the serve, not from dockhand; a row that cuts one should cancel what it leaves.

## Verification

- New tests: a review against a master behind the pull request's base reviews only its own commit, from its own base, and says so; the index is asked only about the directories the base has.
- The full checks: fmt-check, vendor-check, vet, lint, deadcode, and the suite under MacPorts.
