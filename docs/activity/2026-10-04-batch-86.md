## What changed

- **What spent the allowance was the harness's H6, not a command of dockhand's own.** setup's `Next:` line names `dockhand outdated --mine`, and H6 runs every `Next:` line, an outdated as it is, so after each of A10's three setups it asked GitHub of each of the 320 ports A10's maintainer, @herbygillot, has, about three requests a port. Each of A10's own commands, measured in the scratch stage with `-v`, sent 0 to 12. H6 now leaves a `Next:` line with `--mine` or `--all` unverified, as one that asks GitHub of every port. A new user's own `outdated --mine` costs about three requests a port of theirs, within the hour's 5,000 for any but the largest maintainers.
- **Each command says what it spent, every one.** GitHub's `rate_limit` said nothing was spent for the fine-grained token whose calls it refused. `DOCKHAND_GITHUB_LOG`, a file, gets a line a command: its requests to GitHub's API, the `X-RateLimit-Used` GitHub last answered, and the command line. The runner sets it for each row, H6's runs included, and records `github_requests` and `github_used_after` from it.
- **A10's batch example takes `-y`**, which a batch needs without a terminal.
- **A row's teardown runs whatever came before it**, and H7 reads what's left past it, allowed or not: D-R2's setup started both slot VMs, then failed on the rate limit, its assert never ran, and H7 passed them as allowed. D-R2 stops its slots in its teardown. The self-test breaks H7 that way.
