# 2026-10-03: setup, one first-run command and the health check (batch 66)

Batch 66 of the [roadmap](../roadmap.md): the onboarding UX's §6, as the command-line UX review proposes it.

## What changed

- **`dockhand setup`** does what `init` did. It checks the Git dockhand runs, registers the checkout, chooses where worktrees go, and reports Git, MacPorts, the providers, the GitHub login, and the records. The report now also counts the branches from before v3 that nothing tracks, pointing at `clean --legacy`.
- **On a terminal it offers what's missing,** each in turn, each declined by answering no:
  - the GitHub login, through the same device flow;
  - the maintainers line the ports naming your GitHub login write, written with your agreement to the configuration file (`config.SetMaintainer`, beside `SetWorktrees` on one top-level setter). Where it can't infer a line, it prints the line to set;
  - last, defaulting to no since it downloads macOS, the Tart image of this Mac's release.
  
  `-y` offers nothing, and neither does a script. Rerun, it's the health check, under the name newcomers already ran, in place of a `doctor`.
- **`setup tart [release] [--xcode …]`** is `providers setup tart`, and **`setup github [--logout]`** is `auth login` and `auth logout`; the login and logout are one function each (`githubLogin`, `githubLogout`).
- **`init`, `auth`, and `providers` still answer, hidden from help,** so scripts and habits keep working. Every message that named them now names `setup`: errors in `github`, `tart`, `provision`, serve's notices, and the main help's introduction. The provisioning code's pin moves with its one changed message, since images hold nothing new.
- README, usage, and development say `setup`.

## Verification

- On a terminal:
  - the worktrees question, then the login offer declined;
  - Publishing named as not set up, with `setup github`;
  - the maintainer line to set, where none can be inferred;
  - no image offered without Tart.
- Off a terminal: `setup -y` offers nothing.
- The other parts and the old names:
  - `setup github --logout`;
  - `init`, `auth`, and `providers` hidden from help but still answering.
- `SetMaintainer` writes the line at the top level, beside a table, and replaces it again.
- `make test` with `DOCKHAND_TEST_MACPORTS_TCLSH`; fmt-check, vendor-check, vet, deadcode, and lint, each read for its exit status.

## Not yet in the report

The disk under Tart's images, log size, and stale worktrees, which the review lists, are `clean`'s to say today. They join the report when §5's archive and clean work reshapes what clean says.
