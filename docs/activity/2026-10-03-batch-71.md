# 2026-10-03: the quick stage's environment (batch 71)

Batch 71 of the [roadmap](../roadmap.md): step 2a's H2, the quick stage's fixtures (the project's plan/acceptance-harness.md).

## What changed

- **`tools/acceptance/quick.sh`**, and `make acceptance`, build the dockhand under test from this checkout. Each run sets up the environment afresh in `ACCEPT_STATE` (`~/.dockhand-acceptance/quick` unless set), registers it with `dockhand setup -y`, and runs the quick stage's rows there. The environment has:
  - its own database, configuration (worktrees inside it, automatic cleanup off, so it never touches the Mac's shared Tart cache), index and reading caches, and worktrees;
  - a scratch ports clone, sparse to `_resources`, whose master is `upstream.git`, an empty bare repository borrowing the person's ports clone's objects with its master at `ACCEPT_PIN`. The pin is MacPorts' master before 2026-09-01 (026b3878), so the same ports are always due and runs compare. Only `upstream.git` is kept between runs;
  - `fork.git`, a local bare fork, so a push reaches nothing real.
- **`lib/guard.sh` refuses what could touch a person's own state.** A quick run is refused where `DOCKHAND_DB`, `DOCKHAND_CONFIG`, `MACPORTS_TREE`, `DOCKHAND_UPSTREAM`, `DOCKHAND_INDEX_CACHE`, or `DOCKHAND_READING_CACHE` is unset or outside `ACCEPT_STATE`, with paths resolved as macOS names them, `/var` by `/private/var`. A full run is refused but as the test host's `dhtest` user. `run.sh` checks it before anything else, and the self-test proves a run aimed at `~/.dockhand/dockhand.db` does nothing.
- **Row A3**, the first of the quick stage's rows: `dockhand` with no arguments, `status`, `config`, and `--help` on every command `--help` lists, `setup tart` and `setup github` included. It passes where nothing errors and `config --json` gives every setting's source.
- An empty `Next:` segment is no longer counted as one H6 couldn't run.
- tools/acceptance/README.md says how it's used.
