# 2026-10-05: field testing's batch 14 (batch 97)

Batch 97 of the [roadmap](../roadmap.md): field testing's batch 14, run at 82551b6d. It comes after v0.3.0-rc2 (3ab39dcd), and none of it is in that candidate.

## What changed

- **A name no port has suggests its language's port.** "no port named sdnotify" now reads "no port named sdnotify; did you mean py-sdnotify?", from the names MacPorts gives a project's port by the language PortGroups' prefixes, py-, p5-, rb-, and R-, a python-, perl-, or ruby- prefix taken as theirs, each in lower case too, as the port index has them (`macports.LikelyPortNames`).
- **A commit pin's skip says the edit that works.** wezterm pins github.setup to a commit; outdated skipped it saying to "name the version to set", and update refused the version and the commit alike. It now says update can't move a commit pin yet, and the edit that does: `dockhand edit wezterm --no-open`, the commit and the version set, then `dockhand checksums wezterm`. Moving a commit pin is on the roadmap.
- **openssl-sys's hint warns where aws-lc-sys is in the lock too.** Following "openssl-sys links openssl; the Portfile may declare it" put the openssl PortGroup on qsv 24.0.0, whose aws-lc-sys 0.45 build then found OpenSSL 3's headers on CPATH and failed. The hint now says so where the lock has aws-lc-sys.
- **A feature newly pulling a crate that downloads at build** (qsv's viz_static, through webdriver-downloader) is on the roadmap: a crate's name is no reliable signal, and a hold is the person's call.
