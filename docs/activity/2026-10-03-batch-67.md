# 2026-10-03: archive in one step, and clean's findings (batch 67)

Batch 67 of the [roadmap](../roadmap.md): the onboarding UX's §5, and field testing's three cleanup findings at af03bbab.

## What changed

- **`archive` takes the worktree** (`engine.ArchiveBranch`) where it holds nothing the branch's commits don't, as `clean --archived` did. The Git branch, your fork's branch, the checkpoints, the record, and the pull request stay. `--undo` brings it back, and the worktree is checked out again when a command next needs it. Only a worktree dockhand made is removed.
- **A worktree with edits asks: commit or discard.** One with uncommitted edits or untracked files is asked about on a terminal, which is the missing piece field testing found: commit them, discard them, or keep it. "Commit" applies tidy's plan where it needs no words from the person, and otherwise says to tidy first. A script keeps the worktree and says why. `--discard` removes it, edits and all, and `--keep-worktree` keeps any worktree.
- **An open pull request is said**, with `gh pr close`, and archive never closes it.
- **`clean --archived` is hidden.** It stays for a branch archived before archive took worktrees.
- **A batch leaves no empty branch** (finding 1). `update --outdated`, serve, and `bump` start no branch for a port whose edit dockhand can't make (`UpdateRequest.NoHandBranch`), and the port's line says "no branch was started". A person's own update still keeps one, for the edit by hand.
- **`clean` says what it did once** (finding 2): one line a branch, what it removed and what it kept and why, after the plan's blocks; and the branches from before v3 it removed, counted.
- **`--legacy` names what to clean by itself** (finding 3). So `clean --legacy --merged=false` sorts only the branches from before v3. With none of `--merged`, `--closed`, or `--legacy`, clean says so.
- usage says it.

## Verification

- `archive`, via the command line:
  - one with untracked files keeps the worktree and says why;
  - `--discard` takes it, with the Git branch kept;
  - `path` checks it out again;
  - on a terminal, "commit" applies tidy's plan and takes the worktree, and "discard" takes one with untracked files.
- `clean`, via the command line:
  - `clean --archived` still takes one archived before;
  - a merged branch's cleaning said in one line;
  - `clean --legacy --merged=false` accepted, and `--merged=false` alone refused.
- The engine: a refused update started for a batch leaves no branch.
- `make test` with `DOCKHAND_TEST_MACPORTS_TCLSH`; fmt-check, vendor-check, vet, deadcode, and lint, each read for its exit status.
