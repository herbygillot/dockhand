## What changed

- **Each refusal says which it is:** a default branch dockhand can't use, by its name; "archived on GitHub, so nothing can be pushed to it"; "disabled on GitHub"; and a name GitHub gives that isn't one.
- **A renamed or transferred repository is its own error** (`forge.RepositoryMovedError`), and submit refuses it, naming the new name and the remote to point at it: "herbyg-test/macports-ports is now herbyg-test/macports-ports-f3renamed on GitHub, renamed or transferred, and remote origin still names the old one; point it at the new one: git remote set-url origin git@github.com:herbyg-test/macports-ports-f3renamed.git", an SSH URL for a remote that pushes over SSH. It refuses rather than follows: the remote names the repository dockhand pushes to, and a person points it elsewhere, as the trust rule has it.
- **F3's rename step runs `submit --plan --no-check`** with the remotes still naming the old name, asserts those words, and asks for the rename back.
