The five fixes placed in 402b6ba4, taken while v0.4.0's tag waits.

## body-wrap beside a URL (note 9)

libextractor's commit as it stands (72e32cd7, field testing) has no line
over 61 characters, so the reported miss couldn't be reproduced from it;
its message was likely rewrapped after the lint ran. A synthetic
79-character line holding a URL reproduced the theory: `CheckCommits`
found nothing, since a line over 72 was spared wherever it held "://".
It now spares a line that is only a URL, or a trailer whose value ends in a URL, as Generated-By's does, or is
one, as `Closes:` with a ticket's (`urlTrailer`). A sentence holding a
URL is flagged. The rule's text in `explain` says so.
