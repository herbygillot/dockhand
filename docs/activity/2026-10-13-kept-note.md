# A kept --note, said as kept; one repeating the commit body, flagged

Field testing (grafana 13.2.4, macports-ports #35488): the commit was amended
to carry a body after a `--note` had been given. submit then filled the PR's
Description from the body and still kept the note below it as the "Author's
note", so the same change list read twice.

- `prdescription.NoteRepeatsCommits`: half or more of a note's lines, with
  list marks, spacing, and case set aside, are lines of the commits' bodies.
- `engine.SubmitPlan.NoteRepeatsCommits` and `NoteKept`, a note from an
  earlier submit that this one keeps because no `--note` was given.
- submit's Note line says a kept note is "kept from an earlier submit, across
  rewritten commits; --note "" clears it", and flags one that "mostly repeats
  the commit message's body, which the Description gives above it".
