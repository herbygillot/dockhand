# The CI job log's readers move to macports/cilog

2026-10-27, roadmap's move after Then's item 7 (prioritization,
ee48f87d). Item 7 let the engine import buildenv/ghactions for the job
log's readers, where the engine takes buildenv's contract alone and the
command layer composes the providers.

- buildenv/ghactions/logs.go and its tests are internal/macports/cilog:
  `ReadLog`, `Built`, `ListsSubports`, `PortResults`, `Untimed`, and
  `FirstError`, which need model alone and read MacPorts' CI workflow's
  markers, as macports' ci.go reads its matrix.
- ghactions reads its runners' logs with it, and the engine a pull
  request's failed jobs'; the engine's import list names
  internal/macports/cilog, and no provider.
