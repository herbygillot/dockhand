## What changed

- **A Node project's workspaces are read with it.** beekeeper-studio 6.1.4 added `devicon` and `simple-icons` and moved electron from 39.8.5 to 39.8.10 in `apps/studio/package.json`, a yarn workspace, and the comparison said "no license, build file, or dependency changes", since it read the root's manifests alone.
  - `project.Read` reads the `package.json` of each workspace the root's names, in a second pass over the archive, taken only where the root names any, since the root's may come after theirs.
  - Patterns are globs of the path below the root, `**` standing for any depth and `!` leaving one out, as yarn and npm read them; `node_modules` is never a workspace.
  - `ReadPackageJSON` reads `workspaces`, an array or yarn's `{packages: …}` object, and any other shape names none rather than failing the manifest. It reads `license` too, for the license item below.
  - `project.ReaderVersion` is 2, so a kept reading made before doesn't stand.
  - A workspace's manifest is then compared as the root's is, by its path.
