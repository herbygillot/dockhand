# The commands say what they do

The second half of the flag review, done without aliases, since dockhand is unreleased and an alias would only teach a spelling that is already gone.

**Names.** `refresh` is `sync`: it brings the local record into line with the pull request and, after a merge, deletes the local and fork branches, which is more than observing; its help says "with its pull request" so nobody reaches for it to catch up with master, which is `rebase`. `refresh-checksums` is `checksums`, under "Prepare an update", where the heading supplies the verb; the command's name is now separate from the stored action value, which keeps its spelling in every record already written. `--refresh-body` is `--update-body`, with the help still saying it rewrites the environment section and nothing else; the `RefreshBody` record field stays, being JSON-tagged on stored publication specs. Every preview is `--dry-run`, and a preparation's dry run still prints the diff to stdout, since that output is pipeable.

**`status`, `console`, `serve`.** `status` prints the rows once and changes nothing; on a terminal it used to open a live table that claimed jobs, built, and pushed, and `--print` was the way out. That table is `console` now, named for what it is, a control surface with verb keys, and `console --watch` opens it without processing for when a service is driving. `start` is `serve`, and it is more than a rename: `--all-repositories` serves every repository registered in the state database whose checkout exists, which a launchd agent needs since it has no checkout of its own; one serve per database, held by a lock beside it, so a second refuses rather than doubling every poll; being stopped by Ctrl-C or SIGTERM is a clean exit, as launchd reads it; and `--install-launchd` writes the agent's plist under the user's LaunchAgents with the installing shell's PATH and tool variables, and prints the launchctl commands rather than running them, since loading a service into the session is the person's own step. The lock and the repository listing live in `app`, so the CLI's import contract, which forbids concrete stores, holds.

The console's `r` key is `s`. The view's retry verb names `checksums` for the recorded action. The tests that spelled the old names spell the new ones, and the resident-driver test expects a stopped serve to return no error rather than the cancellation it used to surface.
