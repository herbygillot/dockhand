# The rest of the structural pass

The three remaining findings of the [structural review](../reviews/2026-09-19-structural-pass.md), after the vocabulary item landed earlier in the day.

**The table's verbs live with the commands.** `tui` no longer spells `--change`, `--job`, `--detach`, or the verb names. `cli` builds them in `verbArgs`, names the verbs that ask first in `verbConfirms`, and hands both to the table through `tui.Options.Verbs`; the table keeps rendering and key handling and, with no verbs wired, says so on the message strip rather than guessing. The test that moved with them also walks the command tree: for every verb on a tracked and a standalone row, the verb must be a command and every `--flag` it spells must be a flag that command or its parents define, so a renamed flag fails here instead of in someone's terminal.

**Package documentation, as the convention says.** The eight packages created since the 2026-09-15 documentation pass, `archive`, `macports/fidelity`, `macports/patchcheck`, `macports/version`, `subprocess`, `tui`, `version`, and `workflow/view`, carry their overview in `doc.go`; the comments moved unchanged out of the implementation files. The package map in `components.md` now lists `macports/dependency`, `macports/distfiles`, `tui`, and `internal/version`, which the prose already described.

**Policy tested at its seam.** `workflow/policy` exists so that the questions the engine asks about evidence can be answered without a VM or GitHub, and until now it was only exercised through the engine. Its tests now run against a reader held in memory, a struct embedding `state.Reader` that answers jobs, attempts, revisions, changes, pull requests, plans, and verification candidates from maps and panics on anything else, which names a question a test forgot. They cover every outcome `SelectVerification` words, when publication coverage needs a recorded plan and when the initiating target alone proves a shared release, how a publication action is bound to its job for both standalone and combined publication, and the evidence check for a cited attempt, a newer failing one, a target mismatch, and an explicitly unverified publication.
