# The Tested-on table gets a header

The pull request body's environment table had an empty header row and put the macOS version in the left column, "macOS 26.1", with the build and architecture on the right. Now the left column names the component and the right carries everything about its version: `macOS | 26.1 (build 25B77; arm64)`, beside the Xcode, Command Line Tools, MacPorts, and dockhand rows that already read that way. The header says so in bold, **Component** and **Version**, and the delimiter row left-aligns both columns explicitly, header included, since browsers center a header cell by default.
