# 2026-10-03: the quick stage's rows, the fault kit, and the host scripts (batch 72)

Batch 72 of the [roadmap](../roadmap.md): step 2a's H3, H4, and H6 (the project's plan/acceptance-harness.md), with the five fixes of the harness's first shakedown on the M1 (plan/shakedown-2026-10-03.md).

## What changed

- **The quick stage's rows**, `tools/acceptance/rows/`, each a setup, an act, and an assert, from prime-time.md's sections A to F where the quick stage can run them: A0, A3, A5, A10; B1, B2, B3, B10; C2 to C6, C8 to C10; D-I1 to D-I3, D-I6, D-N1, D-R2, D-S3 to D-S9, D-T1 to D-T5; E1 to E10, which run `--plan` only, as section E's dry run; and F4, F6, F9. A row that needs GitHub, a fork, or the full stage's host says so as its result rather than failing.
- **The fault kit**, `lib/fault.sh` and `faultproxy`: a proxy that tunnels without decrypting and stalls, resets, or answers 5xx, set as `HTTPS_PROXY`; `PATH` shims that hide or age a tool; a kept archive's byte flipped, the database truncated, bad TOML. `lib/plan.sh` runs a plan in human and JSON form for the E rows.
- **H6's `Next:` reading** splits a line on ", then ", "; ", and ", or ", drops a parenthesised reason, runs `cd "$(dockhand path X)"` as the cd it is, and adds `--plan` to every verb that changes something.
- **The host scripts**, `tools/acceptance/host/`: `provision-host.sh` (once per Mac), `reset-user.sh` (the full stage's fresh `dhtest`, refused without the host's marker or for any other user), and `stage-candidate.sh` (the candidate's Portfile in the overlay, with `internal/buildinfo.Version` as its ldflag). Each is a dry run unless given `--run`; nothing has run on a host.
- **The shakedown's fixes:**
  1. `quick.sh` pins `DOCKHAND_TART_HOME`, `DOCKHAND_SSH_DIR`, and `TART_HOME` under `$ACCEPT_STATE/tart`, kept between runs with the stage's own image, which `quick.sh --image` makes once; a run without it stops and says so. `lib/guard.sh` refuses a quick run with any of the three outside `ACCEPT_STATE`.
  2. A new invariant, H9: the person's own `~/.dockhand`, `~/.tart`, and `~/.ssh`, whether each is there and each file's size and time, are as they were after every quick row. The harm sweep's own `tart list` had made `~/.tart` where it wasn't; it now lists both Tart homes, and only where each is there.
  3. A command that only reads made dockhand's Tart home: `providers`, through `tart list`, since Tart makes its home's directories on any command. `tart.Client.Images` now says a missing home has no images without running Tart (batch 73's code, with a test).
  4. Results are labelled with the rc tag at HEAD, or HEAD's short commit, never `git describe`'s nearest tag, which named them `design-v3-…`.
  5. `upstream.git` lost objects, through a `gc --prune` of the ports clone it borrows from, is noticed and made again; the README says why.
