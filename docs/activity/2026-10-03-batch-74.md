# 2026-10-03: the full stage's protocol (batch 74)

Batch 74 of the [roadmap](../roadmap.md): step 2a's H7, the full stage's protocol (the project's plan/acceptance-harness.md), with two fixes the quick stage's first local run of its H3 rows found.

## What changed

- **`lib/protocol.sh`**, sourced for every row:
  - `checkpoint "<what>"` stops the run with `WAITING: <what>`, on the runner's output and in `$ACCEPT_STATE/waiting`, until `resume.sh` answers `done`, `skip` (the row is not run), or `fail` (the row fails); `judged "<claim>"` asks a person whether what a row shows holds, and passes it on `done`;
  - `host_only "<what>"` marks a row's first step that needs the test host;
  - the approval list: a row's `# prs: <port> test|real` lines name the pull requests it means to open. Before the first row of a full run, run.sh lists them all in `$ACCEPT_STATE/prs.intended` and checkpoints once; the person deletes a line to decline it and changes `test` to `real` for a real update. `submit_pr` opens only an approved one, and a test one as prime-time.md says: titled `[testing]`, with a `--note` that it tests a release candidate and will be closed, and `--skip-notification`. `close_test_pr` closes it once the row has its evidence and runs `clean --closed`.
- **`full.sh`**, the full stage's entry on the test host as `dhtest`: the user's own ports clone, the installed dockhand, the test account's login for H3, and the day's two ports, with H9 off, since the state is the test's.
- **`run.sh --dry-run`**, and `quick.sh --dry-full`: the full stage's rows in the quick stage's scratch environment, under the quick stage's guard, each stopping as "not run" at its first checkpoint or host-only step. "not run" counts apart from failures.
- **The rows only the host runs**, written: A1, A2, A4, A7, A8; B4 to B9; C1, C7; D-I4, D-I5, D-N2 to D-N5, D-C1 to D-C6, D-S1, D-S2, D-S10, D-R1, D-R3, D-R4; F1 to F3, F5, F7, F8, F10, F11; S1 and S2. Each acts and asserts what a script can, and asks a person to judge what it can't. The fault kit's `PATH` shims gain `old-tart`, a Tart that says 2.38.0, for F8.
- **H6 kept `cd "$(dockhand path X)"`.** Stripping a step's parenthesised reason took the `(dockhand path X)` out of the cd as well, so the step after it ran in the main checkout and was refused (C9's blocker). Only a trailing reason is stripped now.
- **C9 expected signatures that come later.** An archive is signed beside it when it's first served to a guest as a dependency (`binaryarchive.Sign`), not when it's kept, and the small Go port depends on no kept archive. C9 now checks that no archive is signed twice for a key and the second check signed nothing again.

- **README's known issues** gain the quick stage's two known issues so far, pomo's unnamed move (C4) and py-lmdb's planned edit (C6), and serve's doubled line, which didn't recur.
