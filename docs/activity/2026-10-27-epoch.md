# An update to a lower version owes an epoch

2026-10-27, the docs dig's I3 (roadmap 4697148f), after the base-master
fix. `update jq 1.6` on 1.7 wrote a version `port upgrade` never takes,
stranding every install, and said nothing; outdated holds a port ahead of
upstream (`Ahead`), so serve never reaches one.

- **The order is MacPorts' own.** The evaluator answers `compare-versions`
  with base's `vercmp` (`Evaluator.CompareVersions`, and on
  `macports.VersionSession`). upstream's `Resolve` marks an explicit
  version vercmp orders below the current one `Lowers`
  (model.ReleaseSelection); a scheme change it orders forward, 1.7 to
  20260101, isn't (TestALowerExplicitVersionIsMarked).
- **update raises the epoch.** portedit's version edit raises it by one
  before the revision reset (`portfile.RaiseEpoch`): at the literal of the
  one epoch command in the target's scope, else a new line after the
  revision, else after the version, aligned with it. An epoch command
  anywhere else, as py-openssl's inside an `if`, is refused whatever it
  evaluates to, and the candidate must evaluate to the raised epoch.
  update says "Lower version: MacPorts orders 1.6 below 1.7, so the epoch
  is raised by one for port upgrade to install it."
  (TestALowerVersionRaisesTheEpoch.)
- **Checksum groups keep their identity across an added line.** A
  checksum group was keyed by its declaration's index among all the
  Portfile's commands, so the epoch line read as "candidate activated
  different checksum declarations"; the key now counts checksum
  declarations alone (distfiles' Group.Owner), and the index among all
  commands, which a subport's checksum placement reads, is Group.Command.
- **commitrules** (`CheckPortfiles` takes the engine's `versionOrder`):
  `version-order`, an error, for a Portfile whose declared version goes
  lower by vercmp without its epoch rising; and `replaced-by-unchanged`,
  an error, for a `replaced_by` added with the version, revision, and
  epoch all standing, which no upgrade acts on. Both are explained, and
  checked by TestALowerVersionOwesAnEpoch.
