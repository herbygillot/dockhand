# Read-only upstream discovery

Implemented `dockhand outdated <port> [port...]` with human and JSON output. Application composition freezes local committed HEAD once, materializes an isolated source workspace, and binds each source-specific version probe to existing upstream discovery. The CLI reports current, update-available, and unknown results. Unknown observations remain in the output alongside successes and produce a nonzero exit status.

The command opens no SQLite state, accepts no work, moves no refs, fetches no MacPorts master, and downloads no distfiles. It uses existing GitHub/GitLab source interpretation, catalog preferences, livecheck filtering, and calculated-version evaluation. No new dependency or package was introduced. Broader selectors and unattended bump/publication authority are deliberately separate.
