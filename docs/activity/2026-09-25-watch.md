# 2026-09-25: watch

Design v3 §10: `dockhand watch` is the status view, live.

## What changed

- **The live view.** On a terminal, `watch` opens a screen of its own and draws status. It gives the terminal back as it was when it ends.
  - It redraws whenever the journal gains an info-level event, such as a check's progress, a result, a branch's state, or a pull request's reading. It also redraws every 30 seconds, so ages stay true.
  - It polls the journal once a second.
  - Sessions journal their own start and end at verbose level. Status's `serve` line opens an observer session, so those events must not count as news, or the view would redraw itself forever.
- **Commands from the view.** A typed line runs a command on a branch, with that command's own confirmations:
  - `c <branch>` runs check;
  - `l <branch>` shows the logs of its latest check;
  - `t <branch>` runs tidy;
  - `s <branch>` runs submit.

  Enter redraws, `q` quits, and the branch may be left out inside a worktree. The command runs in the view's own streams, so its questions read the same input. Enter then returns to the view.
- **Plain output.** `--plain`, and any output that isn't a terminal, prints status once. It then prints each event as a line with its time, branch, and run, for scrollback, SSH sessions, and screen readers.
- **Observing only.** `watch` starts nothing by being opened. Being stopped is how it ends, not an error.

## A departure from the design

The design says "keys". The view takes a letter and a branch, then Enter, rather than single keystrokes. This avoids putting the terminal in raw mode, which would have to be undone around every command's own prompts. It works the same over SSH and with screen readers, and a branch is named rather than selected with a cursor. Single keystrokes can come with a cursor, if the typed line proves clumsy.

## Tests

- **Plain:** status first, then a foreground check's events as lines, with no session noise. Stopping is a clean exit.
- **Live**, with a pipe standing in for the keyboard:
  - the first draw on its own screen;
  - an unknown letter explained;
  - `archive` in another command redrawing the view;
  - `l` running `logs check-1`, and Enter returning;
  - `q` giving the screen back.
- **Both** ran repeatedly under the race detector.
