# The README for v0.3.1, and a bug-report template

The person decided to announce v0.3.1 now (2026-10-15, relayed), and the
announcement links the README on main and asks for feedback on GitHub.

- **README**: its note names v0.3.1 and says what v0.4.0, which main is
  moving toward, changes: `-b` names only an existing branch, with
  `--new=<name>` to start one; the hidden `auth` goes, `setup` naming the
  login; `ship` comes. "Known issues in v0.3.1": v0.3.0's, which v0.3.1
  keeps, the GH_TOKEN preview item back in the list, since v0.3.1 has it
  and its workaround, `auth status`, still works there. Installing names
  `sudo port install dockhand` first, and the source build clones v0.3.1.
- **`.github/ISSUE_TEMPLATE/bug_report.yml`** asks for `dockhand
  --version`, the command run, what happened and what was expected, the
  check ID where one was involved, and the Mac's macOS and MacPorts.
