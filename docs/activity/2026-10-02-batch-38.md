# 2026-10-02: what field testing found (batch 38)

Batch 38 of the [roadmap](../roadmap.md), taken before item 7's rest at the person's word: the findings of the "Dockhand field testing" thread, dogfooding pushed main (406b7c77, then 034417d0) on the person's checkout across `outdated --mine`, semgrep's update, the argocd, consul, and skim bumps to macports/macports-ports#35093, #35094, and #35103, and the cleanup after. Each finding was checked against the code first; what held is fixed below, and the rest is said at the end.

## What changed

- **The heartbeat stops with its session** (`coord`). `startSession` beat until the command's context ended, but `check` ended its session as it returned, and a bump went on to submit: the next beat, refused for an ended session, said "Couldn't record that this dockhand is still running … another dockhand may take over its work", on three bumps of three. `End` now stops `KeepAlive`, and a session ended before it began beating never starts.
- **An update of a Git-fetched port compares its commits.** Update's assessment compared archives only, and for semgrep's Git clone compared nothing and said nothing, where a revision's assessment reads each version's commit through its forge's archive (`readCommits`). Update reads them the same way now, recording the commit it read. A port that fetches nothing says "Upstream not compared: <port> fetches no upstream source", marked by its coverage's `not-compared` policy, rather than nothing.
- **The comparison in plain words.** The coverage line said "Read LICENSE, go.mod", which reads as an instruction; it says "Compared LICENSE, go.mod" now, and adds how the source was read where that's recorded, a Git port's commits or a subdirectory the archive lacks. A dependency whose requirement changed was "6 moved"; it's "6 changed". Another version of a crate Cargo.lock already pins, skim's nix 0.30.1 beside 0.28, 0.29, and 0.31, was a move; it's an addition, and one of several versions gone a drop.
- **A new major version is said.** semgrep's 0.14.0 to 1.179.0 read as a plain bump; `update` says "A new major version: what depends on semgrep may need to follow", and `--json` carries `crosses_major`. `version.CrossesMajor` compares the first numeric components, leaving out ones above 999, a year or a date, whose first component moves every year.
- **outdated, shorter and quieter.** A subport checked with a sibling that's listed is said on the sibling's row, "update (4 subports with it)", rather than a row each: five python ports took about 25 lines, and a subport's row said "update with py-flatbuffers" while that update was on a branch already. The probes it makes are quiet, so "py-wsaccel is a stub; editing py313-wsaccel" no longer prints from a command that edits nothing. The closing line on set-aside tags says what a livecheck.regex does about one.
- **cargo.crates rows stay on the column.** The layout took a row whose version started past the field, one placed off the column, for the field's start, and placed each new row there: skim's table had 26 rows two to six columns past the rest, each from an earlier update. A field holds every version that ends on its column, so a token starting inside the widest of them is no field start.
- **logs takes a port as an argument**: `logs check-76 semgrep`, and `logs semgrep` in the branch's worktree, where the latest check logged it; elsewhere the error says to name the check.
- **clean reads pull requests first**, as `status --refresh` does: argocd's and consul's merged a minute before, and `clean` left them out, unsaid.
- **A review's age is the review's.** A refresh made a nine-hour-old request for changes read "just now", since the age was when dockhand last read it. GitHub's reviews carry their submission time; the observation keeps the latest of the reviews that set its state, and status ages a request for changes by it.
- **Fetching master is said when it's slow**, after two seconds: a bump said nothing for twenty before "Started".
- **archive says how a branch done with goes**: `dockhand clean --archived <branch>` removes its worktree, which archive alone doesn't.

Naming MacPorts' phase, and the failing command from the log, needs the log read on the guest; carried in the roadmap.
