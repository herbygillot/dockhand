# 2026-09-25: v2 frozen, and its command layer cleared

Roadmap step 4, as the person approved it. Work now happens on `main`.

## What changed

- **Tags.** `v2-final` is an annotated tag on `a9c8aaf`, the last commit whose binary is the v2 tool. `design-v3` marks the same commit. Tag pushes are refused from this session (HTTP 403), so both tags exist only locally here and the person pushes them.
- **Deleted.**
  - `internal/cli`, `internal/tui`, `internal/app`, and `internal/proc`: v2's command line, live table, composition, and process manager.
  - The modules only they used: bubbletea, lipgloss, and 17 indirect ones. pflag stays, now indirect through cobra.
  - The vendor directory was refreshed with `make vendor`, and `make vendor-check` is clean.
- **Added.** `internal/command` holds v3's command line. Its root prints the rebuild notice, names `v2-final`, and says how to build it, and it answers `--version`. `cmd/dockhand` now calls it.
- **Moved.** The GitHub OAuth client ID moved from `app` to `github.DefaultOAuthClientID`, and the Makefile's `GITHUB_OAUTH_CLIENT_ID` stamps it there.
- **README.** A note at the top says `main` is being rebuilt and points to `v2-final`.

## What stays, and why

`workflow`, `record`, `state`, `state/sqlite`, `publish`, and `tools/stateperf` stay. The roadmap as first written deleted them here. But the GitHub provider's test fixture and several Tart tests drive `workflow`'s engine. Those tests are where the reconciliation, idempotent-submission, and uncertain-write rules are checked, and they are the rules the rebuild ports. Each of these packages is deleted in step 5, when its replacement exists and those tests are rewritten against it. Nothing outside them imported the deleted command layer, so the cut was clean.

## The guest channel moves after the freeze

Step 3 needs a Mac to prove: Tart, SSH to real guests, and macOS Local Network privacy (decision 43). This session runs on Linux. Building the channel on v2's provider first, then again on the reshaped one, would do the work twice. So it is now built once, on step 5's providers. `v2-final` keeps `tart exec`: its verdicts are safe, but its host-side logs from macOS 12–15 guests can be incomplete (decision 42).

## Validation

`make test`, `make vet`, `make vendor-check`, and `make build` pass on Linux, and `make test-race` was run too. The built binary prints the notice and its version.
