# dockhand v2's documents

These pages describe dockhand v2 as it was at the tag `v2-final`: its commands (`bump`, `verify`, `publish`, `console`), its architecture and packages, its database, `~/.dockhand/state.db`, and its output. They are kept for that history, and for the activity notes and reviews that link them.

v3 replaced them on 2026-09-26. Its guide is [`../usage.md`](../usage.md), its design [`../design-v3.md`](../design-v3.md), and its map of the code [`../architecture.md`](../architecture.md).
