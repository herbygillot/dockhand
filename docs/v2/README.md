# dockhand v2's documents

These pages describe dockhand v2 as it was at the tag `v2-final`: its commands (`bump`, `verify`, `publish`, `console`), its architecture and packages, its database, `~/.dockhand/state.db`, and its output. They are kept for that history, and for the activity notes and reviews that link them. v2's code was deleted on 2026-09-27; commit `1cbcdf8b65` is the last with it, and links from these pages and the reviews to its files lead nowhere now.

[`resolution-design.md`](resolution-design.md) is v2's contribution resolution design, moved here with the code it described.

[`roadmap.md`](roadmap.md) is the roadmap as it stood until 2026-09-27: v2's queue and completed capabilities, the reviews it triaged, and v3's rebuild in thirteen steps. The [current roadmap](../roadmap.md) replaced it, carrying forward every item it left open.

v3 replaced them on 2026-09-26. Its guide is [`../usage.md`](../usage.md), its design [`../design-v3.md`](../design-v3.md), and its map of the code [`../architecture.md`](../architecture.md).
